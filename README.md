# Study Abroad Help – MBBS in Kyrgyzstan 🇰🇬

An honest, student-first guidance website for Indian students planning to study **MBBS in Kyrgyzstan**.

This project focuses on **clarity, transparency, and realistic guidance** — especially for students and parents confused by misleading agents and unrealistic promises.

## 🌟 Key Features
- Honest explanation of **Why Kyrgyzstan for MBBS**
- Detailed **university information**
- Transparent **fees comparison: Kyrgyzstan vs India**
- Clear **eligibility criteria (NEET, PCB, NMC rules)**
- Step-by-step **admission process**
- Recognition & validity (WHO / NMC / FMGE–NExT reality)
- Student-friendly UI with mobile support
- Direct WhatsApp guidance (no hidden charges)

## 🎯 Target Audience
- Indian NEET aspirants
- Parents seeking safe & affordable MBBS options
- Students exploring MBBS abroad with realistic expectations

## ⚠️ Important Note
This website does **not** promise:
- Guaranteed FMGE/NExT results  
- Fake rankings or unrealistic salaries  

The goal is **informed decision-making**, not sales.
